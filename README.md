# TALLER_RECURSIVIDAD
ESTUDIANTE: WILSON ARLEY RUIZ RUIZ

DESCRIPCION DEL TALLER: Este taller reúne una serie de 13 ejercicios de programación en Java enfocados en el tema de recursividad dentro de la asignatura de Estructuras de Datos Lineales en Ingeniería Informática. Cada ejercicio aborda problemas clásicos como factorial, sumatorias, inversión de números, máximo común divisor, serie de Fibonacci y la función de Ackermann, entre otros.

El objetivo es:

.Practicar la implementación de algoritmos recursivos.

.Aplicar principios de clean code (código limpio, modular y legible).

.Reforzar la lógica computacional y la resolución de problemas.

.Cada clase Java contiene:

.El enunciado del ejercicio como comentario inicial.

.Métodos con nombres claros y responsabilidades únicas.

.Uso de Scanner para entrada de datos (variable llamada ESCANEAR).

.Ejemplos de validación básica de entradas.

iNSTRUCCIONES PARA EJECUTAR LOS PROBLEMAS DESDE CERO:

-Clonar o descargar el proyecto en tu computadora.

-Asegúrate de tener instalado Java JDK 8 o superior.

-Abre una terminal en la carpeta donde se encuentran los archivos .java.

-Compila el archivo correspondiente al ejercicio que quieras probar. Por ejemplo, para el factorial:

javac Factorial.java (EN BASH)

Ejecuta el programa compilado:

java Factorial (EN BASH)

Ingresa los datos solicitados por consola y observa el resultado.

Repite los pasos 4 y 5 para cada uno de los ejercicios (Sumatoria.java, InvertirNumero.java, MCD.java, Fibonacci.java, etc.).
